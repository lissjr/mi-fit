# 小米运动 FIT

把小米运动健康里的跑步、睡眠、心率、体重，导成标准 FIT 文件，并可直接上传佳明中国。

## 它解决什么

小米运动健康的数据存在手机本地，官方只给自家 App 用，导不出通用格式。想换到佳明、Strava，只能一条条手动录。

这个 App 直接读本地库，把记录还原成 FIT：跑步带轨迹、计圈、功率，体重带体脂和肌肉量。上传到佳明后，Connect 里就是一条原生记录。

## 原理

数据在 `com.mi.health` 的私有目录：



* `databases/2203130080/cn/fitness_data` —— 主库，67 张表

* `files/fitness` —— 活动文件，逐点轨迹和心率采样按场次存放

关键表：



| 表                               | 内容                         |
| ------------------------------- | -------------------------- |
| `sport_report`                  | 每场运动，JSON 存时间、距离、心率、卡路里、功率 |
| `sleep_segment`                 | 每晚一条，睡眠分期、平均心率、平均 HRV      |
| `hr_record`                     | 日常心率，60 秒一个平均 bpm          |
| `step_record`                   | 步数，分钟级区间值                  |
| `spo2_record` / `stress_record` | 血氧、压力                      |
| `weight_item_record`            | 称重记录，体重体脂肌肉量               |
| `training_load_record`          | 每日训练负荷                     |

App 用 root 直接读这些文件，按 SQLite 页结构自己解析（不依赖 sqlite3 命令行），再按 FIT 协议编码成 `.fit` 二进制。

写入佳明走 `upload-service/upload/.fit`：活动文件直接传，生理数据用 `weight_scale` 消息，佳明会识别成体脂秤数据。

## 功能



* 健康 / 运动 / 我的 三页，液态玻璃风格，MiSans 字体

* 运动列表与详情：配速、心率、步频、功率、爬升、分段、地图轨迹

* FIT 导出：单场或批量，1 公里自动计圈

* 直连佳明中国：活动自动上传，体重体脂肌肉量同步

* 健康总览：今日心率、血氧、压力、步数、体重趋势、睡眠分期、睡眠 HRV 趋势、训练负荷

* 本机数据加密：佳明令牌和缓存用 Android Keystore 加密存放

## 运行要求



* Android 8.0 以上

* 手机已 root（Magisk / KernelSU），App 通过 `su` 读小米运动健康的私有目录

* 已安装小米运动健康，库里要有数据

不 root 用不了。那些文件属于 `com.mi.health` 的私有目录，普通应用没有读权限。

## 构建

需要 JDK 17+、Android SDK（build-tools 与 platform 34）。



```
$env:ANDROID_HOME = "C:\Android\Sdk"
.\build.ps1
```

产物是根目录的 `mi_fit_export.apk`。首次构建自动生成调试签名。纯 javac + aapt2 + d8 手工链路，不用 Gradle，不引入任何第三方依赖。

## 数据去向



* 数据只在本机读取和展示

* 只有你手动开「自动上传」后，运动记录才会发到你自己的佳明账号

* 佳明密码只在登录时用一次，换回的令牌加密存在本机，退出登录即清除

* 不上传第三方服务器，没有统计埋点

## 已知限制



* 小米只给睡眠 HRV。日常心率是 60 秒一个平均值，没有逐拍 RR，算不了全天 HRV

* 心率、睡眠、血氧写不进佳明。佳明只开放活动文件和体成分两条通道

* 自动同步是前台触发，锁屏后不传
